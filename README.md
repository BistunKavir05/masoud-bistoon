# بیستون — مدیریت و کنترل پروژه

سامانه‌ی چندکاربره‌ی مدیریت و کنترل پروژه برای تیم‌های کوچک (حدود ۱۰ کاربر): زمان‌بندی (CPM)، گانت، منابع و تقویم، پیشرفت و خط مبنا،
منحنی S و ارزش کسب‌شده، هزینه و مالی، منشور و قرارداد، ریسک/مسئله/تغییر/تصمیم، مستندات، گفتگو، گزارش‌ها و پورسانت.
رابط کاملاً فارسی و راست‌به‌چپ است؛ تاریخ‌ها شمسی نمایش داده می‌شوند و میلادی (ISO) ذخیره می‌شوند. هیچ منبعی از اینترنت (CDN، فونت) بارگذاری نمی‌شود.

برنامه‌ی تک‌فایلی اولیه به‌عنوان مرجع رفتار در `reference/bistoon-v34.html` نگه‌داری می‌شود و هیچ‌گاه تغییر نمی‌کند؛
اختلاف‌های عمدی با آن در `docs/divergences.md` ثبت است.

## امکانات

- **۱۷ تب:** داشبورد، فعالیت‌ها، گانت، منابع، تقویم، منحنی S، مالی، منشور و قرارداد، ریسک/مسئله، تغییر، تصمیم، مستندات، گفتگو، گزارش تغییرات، گزارش وضعیت، پورتفولیو، کاربران.
- **فعالیت‌ها:** سلسله‌مراتب تا ۹ سطح، وابستگی FS/SS/FF/SF با تأخیر، فعالیت تکرارشونده (روزانه/هفتگی/ماهانه/سالانه)، تراز منابع، خط مبنا و اسنپ‌شات.
- **نقش‌ها به‌ازای هر پروژه:** ادمین، مدیر پروژه، بازرگانی، مالی، مدیریت، کارشناس — قابل تغییر در هر پروژه. بازرگانی فقط پورسانت، وضعیت/مرحله‌ی پروژه، مبلغ قرارداد، صورتحساب و وصول را می‌بیند. پورسانت پس از وصول پرداختنی می‌شود و «حسن انجام کار» در هر قرارداد مبلغ ثابت یا درصدی از قرارداد است.
- **ورود/خروج داده:** پشتیبان JSON با پیش‌نمایش، ورود نسخه‌ی قدیمی برنامه، MS Project (XML؛ ورود و خروج)، CSV (با محافظت در برابر تزریق فرمول)، ساخت پروژه‌ی جدید از چند منبع؛ گزارش وضعیت قابل چاپ (PDF از چاپ مرورگر).
- **ممیزی:** هر تغییر با نام کاربر و زمان ثبت می‌شود و از داخل پایگاه‌داده قابل ویرایش نیست.

## ساختار مخزن

| مسیر | محتوا |
| --- | --- |
| `packages/core` | هسته‌ی دامنه به TypeScript (تقویم، شمسی، CPM، پیشرفت، خط مبنا، منحنی S، EVM، پورسانت، ساختار فعالیت‌ها، تکرار، ورود MS Project). بدون وابستگی به DOM/React/پایگاه‌داده؛ هم سرور و هم رابط از آن استفاده می‌کنند. |
| `apps/api` | سرویس Express 5 و PostgreSQL: نشست با کوکی + CSRF، نقش‌ها به‌ازای پروژه، همزمانی خوش‌بینانه، ممیزی |
| `apps/web` | رابط React 19 (ساخت با esbuild) |
| `db/migrations` | migrationهای SQL (با checksum؛ فایل اجراشده هرگز ویرایش نمی‌شود)، `db/tests` آزمون SQL |
| `deploy` | کیت استقرار: Docker Compose، systemd، nginx، پشتیبان‌گیری/بازیابی — **راهنمای نصب: [`deploy/README.md`](deploy/README.md)** |
| `tools/oracle` | آزمون تفاضلی: همان پروژه‌ی تصادفی را در برنامه‌ی مرجع و هسته‌ی جدید محاسبه و مقایسه می‌کند |
| `docs` | تصمیم‌ها و اختلاف‌های عمدی |

## اجرا برای توسعه

نیازمندی: Node.js ‎≥ 22.18 و PostgreSQL 16.

    npm install
    export DATABASE_URL=postgres://postgres:postgres@127.0.0.1:5432/bistoon     # پایگاه‌داده‌ی خالی
    npm run migrate -w @bistoon/api
    npm run create-admin -w @bistoon/api -- --username admin                   # گذرواژه‌ی موقت چاپ می‌شود
    npm run build -w @bistoon/web
    WEB_DIST=../web/dist npm start -w @bistoon/api                              # http://127.0.0.1:3000

(برای توسعه‌ی رابط: `npm run dev -w @bistoon/web` ساخت را با هر تغییر دوباره انجام می‌دهد.)

## آزمون‌ها

    npm run typecheck                                  # هسته، API، رابط
    npm test                                           # آزمون واحد همه‌ی بسته‌ها (آزمون API به TEST_DATABASE_URL نیاز دارد)
    TEST_DATABASE_URL=postgres://postgres:postgres@127.0.0.1:5432/postgres npm test -w @bistoon/api
    ./db/tests/run.sh                                  # آزمون SQL (PGHOST/PGUSER… را تنظیم کنید)
    npx playwright install chromium
    npm run build -w @bistoon/web && cd apps/web && node --test --test-concurrency=1 e2e/*.e2e.ts   # آزمون انتها‌به‌انتها با مرورگر واقعی
    node tools/oracle/run.ts --count 100 --seed 1      # مقایسه با برنامه‌ی مرجع (Playwright)

CI (GitHub Actions) همه‌ی این‌ها را به‌اضافه‌ی ساخت و آزمون دودی تصویر Docker اجرا می‌کند.

## محدودیت‌های شناخته‌شده

- جدول فعالیت‌ها همه‌ی ردیف‌ها را رندر می‌کند (مجازی‌سازی ندارد). با ۱٬۲۰۰ فعالیت آزمایش شد و روان بود؛ برای ده‌ها هزار ردیف مناسب نیست.
- گفتگو با polling کار می‌کند؛ حذف پیام دیگران تا بارگذاری دوباره دیده نمی‌شود.
- لنگر خط مبنا پس از بایگانی دوباره فعال نمی‌شود (باید خط مبنای جدید گرفت).

وضعیت مراحل و آنچه تأیید شده در [`PROGRESS.md`](PROGRESS.md) است.
